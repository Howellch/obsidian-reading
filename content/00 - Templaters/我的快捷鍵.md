# 我的快捷鍵

## 技術描述

- 清除每行開頭的 tab 和 空格
	- $ctrl + shift +$ ~
	
- 清除顏色
	- $ctrl + alt +$ ~
	
- 背景顏色
	$Purple : ctrl + shift + 1$
	$Yellow : ctrl + shift + 2$
	$Red : ctrl + shift + 3$
	$Green : ctrl + shift + 4$
	$Pink : ctrl + shift + 5$
	$Blue : ctrl + shift + 6$
	$Brown : ctrl + shift + 7$
	$gary : ctrl + shift + 8$

- 前景顏色
	$Purple : ctrl + alt + 1$
	$Yellow : ctrl + alt + 2$
	$Red : ctrl + alt + 3$
	$Green : ctrl + alt + 4$
	$Pink : ctrl + alt + 5$
	$Blue : ctrl + alt + 6$
	$Brown : ctrl + alt + 7$
	$gary : ctrl + alt + 8$

- 標記顏色
	$Blue : ctrl + alt + 9$
	$Coral : ctrl + alt + 0$
	$Green : ctrl + alt + (-)$
	$Pink : ctrl + alt + (+)$
	$Purple : ctrl + alt + [$
	$Yellow : ctrl + alt + ]$

### 開發 / 架構
- **FSP** = Flexible Software Package：Renesas BSP / Driver / Code Generation 軟體包
- **SSC** = Slave Stack Code：EtherCAT SubDevice Stack Code
- **SSC Tool**：ETG 用來產生 EtherCAT Stack 的工具
- **SMCRK** = Safety Motor Control Reference Kit
- **ETG** = EtherCAT Technology Group
- **CPU0**：RZ/T2M Motor Control
- **CPU1**：RZ/T2M EtherCAT / CiA402
- **Shared Memory**：CPU0 ↔ CPU1 資料交換
- **FuSa** = Functional Safety
- **I/F** = Interface

### EtherCAT
- **ESI** = EtherCAT SubDevice Information：TwinCAT 用的 Device XML
- **MII** = Media Independent Interface：EtherCAT Controller ↔ PHY Data Interface
- **PHY** = Physical Layer Transceiver：Ethernet 實體層
- **MDC** = Management Data Clock
- **MDIO** = Management Data I/O：PHY Register 管理介面
- **GMAC** = Gigabit Media Access Controller：本 Sample 借用其 MDIO 功能管理 PHY
- **CoE** = CANopen over EtherCAT：CANopen / CiA402 資料模型跑在 EtherCAT
- **PDO** = Process Data Object：週期即時資料
- **RxPDO**：Master → Drive
- **TxPDO**：Drive → Master
- **SDO** = Service Data Object：非週期 Parameter 存取
- **DC** = Distributed Clock：EtherCAT 高精度同步
- **SM** = Sync Manager：EtherCAT Process Data Synchronization
- **PDI** = Process Data Interface：ESC ↔ Application CPU
- **PDU** = Protocol Data Unit：Protocol Packet
- **SCI** = Serial Communication Interface：UART Peripheral
- **DMAC** = Direct Memory Access Controller：Peripheral ↔ Memory 自動搬資料
- **CMT** = Compare Match Timer：Timer Peripheral

### CiA402
- **CiA402**：Servo Drive 標準操作介面
- **FSA** = Finite State Automaton：Drive State Machine
- **Control Word `0x6040`**：Master → Drive State Command
- **Status Word `0x6041`**：Drive → Master State Feedback
- **Object Dictionary**：Drive 對外 Parameter / Variable Table
- **PP** = Profile Position：Drive 自己產生 Position Profile
- **HM** = Homing Mode：建立 Position Reference
- **CSP** = Cyclic Synchronous Position：週期 Position Command
- **CSV** = Cyclic Synchronous Velocity：週期 Velocity Command
- **CST** = Cyclic Synchronous Torque：週期 Torque Command

### Motor
- **PMSM** = Permanent Magnet Synchronous Motor
- **FOC** = Field-Oriented Control
- **Vector Control**：磁場導向式 Motor Control
- **Inverter**：PWM → 三相 U / V / W Power
- **Encoder**：Motor Position Feedback

### Safety
- **FSoE** = Fail Safe over EtherCAT
- **STO** = Safe Torque Off：安全取消 Torque
- **SS1-t** = Safe Stop 1 – Time Controlled：先停止再 STO
- **HFT** = Hardware Fault Tolerance
- **SafeData**：Safety Application Data
- **RZ/T2L-A / B**：雙 Safety CPU

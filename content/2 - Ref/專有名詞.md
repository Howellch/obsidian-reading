## 1. 開發平台、軟體與系統架構

| 名詞                  | 全名                                 | 簡易解釋                                                                                                            |
| ------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **FSP**             | Flexible Software Package          | Renesas 的韌體軟體包，包含 BSP、Driver、Peripheral Module、Code Generation 等，用來降低直接操作硬體 Register 的工作量。                      |
| **SSC**             | Slave Stack Code                   | ETG 提供的 EtherCAT Stack Code；透過 SSC Tool 產生 EtherCAT SubDevice 所需的 Protocol Stack。文件使用的 SSC Tool Version 為 5.13。 |
| **SSC Tool**        | Slave Stack Code Tool              | ETG 提供的工具，用來依 EtherCAT Device Configuration 產生 EtherCAT Stack Source Code。                                      |
| **SMCRK**           | Safety Motor Control Reference Kit | 本專案名稱中的縮寫，可理解為 RZ/T2M + RZ/T2L Safety Motor Control Reference Kit。                                              |
| **ETG**             | EtherCAT Technology Group          | EtherCAT 技術組織，負責 EtherCAT 規格、SSC Tool、測試與相關技術規範。                                                                |
| **e² studio**       | Renesas e² studio                  | Renesas 的 IDE；本專案用來 Build、Flash、Debug RZ/T2M Firmware。                                                          |
| **TwinCAT**         | Beckhoff TwinCAT 3                 | 本 Sample 使用的 Software PLC / EtherCAT Master，用來 Scan Device、設定 PDO、CiA402、FSoE 並控制 Motor。                        |
| **PLC**             | Programmable Logic Controller      | 工業控制器；在此架構中可以扮演 EtherCAT Master，對 Servo Drive 發送 Command。                                                       |
| **ICE**             | In-Circuit Emulator                | 硬體除錯工具的統稱，用來 Flash、Breakpoint、Single Step、查看 Memory / Register。                                                 |
| **J-Link**          | SEGGER J-Link                      | 本 Sample 用來 Debug / Flash RZ/T2M 的 Emulator。                                                                    |
| **I-jet**           | IAR I-jet                          | 本 Sample 用來開發 / 燒錄 RZ/T2L Functional Safety Firmware 的 Debugger。                                                |
| **BSP**             | Board Support Package              | 板級支援層，負責 Clock、Pin、Board Initialization 等硬體基礎設定。                                                                |
| **I/F**             | Interface                          | 文件常見縮寫，例如 `Motor CPU I/F`、`Fusa I/F`，就是兩個 Module / CPU 之間的介面。                                                   |
| **Shared Memory**   | Shared Memory                      | RZ/T2M CPU0 與 CPU1 共用的 Memory，用於 Motor Control 與 EtherCAT / CiA402 之間交換 Command、Status。                         |
| **CPU0**            | RZ/T2M CPU Core0                   | 本 Sample 主要執行 Motor Control、Position / Speed / Current Control。                                                 |
| **CPU1**            | RZ/T2M CPU Core1                   | 本 Sample 主要執行 EtherCAT、CiA402、Motor CPU I/F 與 Safety Communication。                                             |
| **Motor CPU I/F**   | Motor CPU Interface                | CPU1 與 CPU0 之間的介面；主要利用 Shared Memory 傳送 Servo Command / Feedback。                                               |
| **Network CPU I/F** | Network CPU Interface              | CPU0 端對應 CPU1 Network Side 的 Shared Memory Communication Module。                                                |
| **FuSa**            | Functional Safety                  | Renesas 程式名稱中常將 Functional Safety 縮寫成 `FuSa`，例如 `Fusa I/F`。                                                     |
| **Fusa I/F**        | Functional Safety Interface        | RZ/T2M CPU1 與 RZ/T2L Safety CPU 之間的通訊介面，本 Sample 使用 SCI / UART。                                                 |
| **hal_entry**       | HAL Entry Function                 | FSP Application 進入主要 Application Processing 的入口之一；本 CPU1 Sample 會在此完成各 Module 初始化再進入 Main Loop。                 |

## 2. EtherCAT 與網路通訊

| 名詞                           | 全名                                                  | 簡易解釋                                                                                                                                   |
| ---------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **EtherCAT**                 | Ethernet for Control Automation Technology          | 工業即時 Ethernet；本專案主要負責 PLC / TwinCAT 與 Servo Drive 交換即時控制資料。                                                                            |
| **EtherCAT Master**          | EtherCAT Master                                     | 控制 EtherCAT Network 的上位端；此 Sample 主要使用 TwinCAT。                                                                                        |
| **EtherCAT SubDevice**       | EtherCAT SubDevice                                  | 接受 Master 控制的 EtherCAT Device；本專案的 RZ/T2M Servo Drive 就是 SubDevice。                                                                    |
| **EtherCAT SubDevice Stack** | EtherCAT SubDevice Protocol Stack                   | 處理 EtherCAT State、PDO、Mailbox、CoE 等通訊協定的 Software Stack。                                                                               |
| **ESC**                      | EtherCAT Slave Controller / SubDevice Controller    | EtherCAT 即時通訊的 Hardware Controller；RZ/T2M 內建 EtherCAT Controller。                                                                      |
| **ESI**                      | EtherCAT SubDevice Information                      | 描述 EtherCAT Device 的 XML File，讓 TwinCAT 知道 Device Identity、PDO、Object 等資訊；此 Sample 提供 `Renesas EtherCAT RZT2 SafetyMotorSolution.xml`。 |
| **EEPROM**                   | Electrically Erasable Programmable Read-Only Memory | EtherCAT Device 可儲存辨識與 Configuration 資訊；文件流程會透過 TwinCAT 寫入後 Reset RZ/T2M 重新載入。                                                         |
| **PHY**                      | Physical Layer Transceiver                          | Ethernet Physical Layer IC，負責 RZ/T2M 數位訊號與 RJ45 實際 Ethernet Electrical Signal 之間的轉換。                                                   |
| **MII**                      | Media Independent Interface                         | RZ/T2M EtherCAT Controller 與 Ethernet PHY 之間傳輸 Ethernet / EtherCAT Data 的數位介面。                                                         |
| **MDC**                      | Management Data Clock                               | MDIO PHY Management Interface 使用的 Clock Signal。                                                                                        |
| **MDIO**                     | Management Data Input/Output                        | 用來讀寫 Ethernet PHY Register，例如 PHY 設定、Link Status；不是用來傳 EtherCAT Process Data。                                                          |
| **GMAC**                     | Gigabit Media Access Controller                     | RZ/T2M 內部 Ethernet MAC Hardware Block；本 Sample 的 `MDIO type = GMAC` 表示利用 GMAC Hardware 的 MDIO 功能管理 PHY。                                |
| **CoE**                      | CANopen over EtherCAT                               | 在 EtherCAT 上使用 CANopen 的 Object Dictionary / SDO / CiA402 資料模型。                                                                        |
| **Mailbox**                  | EtherCAT Mailbox                                    | EtherCAT 非週期性通訊機制之一；CoE / SDO 等服務透過 Mailbox 處理。                                                                                        |
| **PDO**                      | Process Data Object                                 | EtherCAT 週期即時資料，例如 Target Position、Actual Position，主要用於 Servo 即時控制。                                                                    |
| **RxPDO**                    | Receive Process Data Object                         | **Drive 接收到的 PDO**；方向是 Master → Drive，例如 Control Word、Target Position。                                                                 |
| **TxPDO**                    | Transmit Process Data Object                        | **Drive 傳出去的 PDO**；方向是 Drive → Master，例如 Status Word、Actual Position。                                                                  |
| **SDO**                      | Service Data Object                                 | 非週期性的 Object Dictionary 存取方式，適合 Parameter Configuration、讀寫設定，而非高速週期控制。                                                                 |
| **Object Dictionary**        | Object Dictionary                                   | EtherCAT / CoE Device 對外公開的標準化 Parameter / Variable Table，例如 `0x6040`、`0x6041`、`0x607A`。                                               |
| **DC Mode**                  | Distributed Clock Mode                              | EtherCAT Master 與各 SubDevice 使用共同的高精度時間基準進行同步，適合多軸 Motion Control。                                                                     |
| **SM Mode**                  | Sync Manager Synchronous Mode                       | 以 EtherCAT Sync Manager / Process Data Event 驅動 Application Processing 的同步方式。                                                          |
| **SYNC0 / SYNC1**            | Distributed Clock Sync Signals                      | EtherCAT DC 產生的週期同步事件，可觸發 CPU 執行固定 Timing 的控制處理。                                                                                       |
| **PDI**                      | Process Data Interface                              | EtherCAT Controller 與 Application CPU 之間交換 Process Data 的介面。                                                                           |
| **PDU**                      | Protocol Data Unit                                  | 某個 Protocol 定義的資料封包單位；文件中特別常看到 FSoE Safety PDU。                                                                                        |
| **SCI**                      | Serial Communication Interface                      | RZ/T2M / RZ/T2L 的 Serial / UART Peripheral；Sample 用它交換 Functional Safety Data。                                                         |
| **DMAC**                     | Direct Memory Access Controller                     | 在 CPU 不需要逐 Byte 搬資料的情況下，直接協助 Peripheral 與 Memory 進行資料傳輸。                                                                               |
| **CMT**                      | Compare Match Timer                                 | RZ/T2M Timer Peripheral，可為 EtherCAT / Application 提供週期 Timing。                                                                         |

## 3. CiA402 與 Servo Motion

| 名詞                             | 全名                                  | 簡易解釋                                                                                   |
| ------------------------------ | ----------------------------------- | -------------------------------------------------------------------------------------- |
| **CiA402**                     | CAN in Automation Drive Profile 402 | Servo Drive 的標準操作介面，規定 State Machine、Motion Mode、Control / Status 與 Object Dictionary。 |
| **Drive Profile**              | Drive Device Profile                | 規定 Servo Drive「對外應該怎麼被操作」，而不是規定內部 FOC 怎麼寫。                                             |
| **FSA**                        | Finite State Automaton              | CiA402 的有限狀態機，規定 Drive 如何在 Disabled、Ready、Enabled、Fault 等 State 間轉換。                   |
| **Control Word**               | CiA402 Control Word                 | Master 給 Drive 的 State Command，標準 Object 為 `0x6040`。                                   |
| **Status Word**                | CiA402 Status Word                  | Drive 回報目前 State，標準 Object 為 `0x6041`。                                                 |
| **Mode of Operation**          | CiA402 Operating Mode               | 指定 Drive 現在要使用 PP、CSP、CSV、HM 等控制模式。                                                    |
| **Modes of Operation Display** | Operating Mode Feedback             | Drive 回報實際目前使用的 CiA402 Operating Mode。                                                 |
| **Operation Enabled**          | CiA402 State                        | Drive 已完成 Enable 流程，可正式執行 Motion Command 的狀態。                                          |
| **Switch On Disabled**         | CiA402 State                        | Drive 尚未允許輸出動力的 State，是常見的起始狀態之一。                                                      |
| **Ready to Switch On**         | CiA402 State                        | Drive 基本條件正常，可以繼續往 Enable 方向轉換。                                                        |
| **Switched On**                | CiA402 State                        | Drive 已 Switch On，但還沒完全進入 Operation Enabled。                                           |
| **Quick Stop Active**          | CiA402 State                        | Drive 正在執行 Quick Stop 相關行為。                                                            |
| **Fault Reaction Active**      | CiA402 State                        | 發生 Fault 後，Drive 正在執行 Fault Reaction。                                                  |
| **Fault**                      | CiA402 State                        | Drive 發生錯誤並停止正常 Motion，需要 Fault Reset 才能恢復。                                            |
| **Error Code**                 | CiA402 Error Code                   | `0x603F`，用來指出 Fault 原因，例如 Overcurrent、Overvoltage、Overspeed、STO / SS1-t。               |
| **Target Position**            | Target Position                     | Master 給 Drive 的位置命令，常見 Object `0x607A`。                                               |
| **Position Actual Value**      | Position Actual Value               | Drive 回傳的實際位置，常見 Object `0x6064`。                                                      |
| **Target Velocity**            | Target Velocity                     | Master 給 Drive 的速度命令。                                                                  |
| **Velocity Actual Value**      | Velocity Actual Value               | Drive 回傳的實際速度。                                                                         |

---

| 縮寫      | 全名                          | 簡易解釋                                              | Sample 支援      |
| ------- | --------------------------- | ------------------------------------------------- | -------------- |
| **PP**  | Profile Position            | 給目標位置、速度、加速度，由 Drive 自己產生 Position Profile 做點到點移動 | ✅ 支援           |
| **HM**  | Homing Mode                 | 建立 / 調整 Servo Position Zero Reference             | ✅ 支援           |
| **CSP** | Cyclic Synchronous Position | Master 每個 EtherCAT Cycle 週期性送 Target Position     | ✅ 支援           |
| **CSV** | Cyclic Synchronous Velocity | Master 每個 EtherCAT Cycle 週期性送 Target Velocity     | ✅ 支援           |
| **CST** | Cyclic Synchronous Torque   | Master 每個 Cycle 週期性送 Torque Command               | ❌ 此 Sample 不支援 |
| **PV**  | Profile Velocity            | Drive 依 Profile 執行速度控制                            | ❌ 此 Sample 不支援 |
| **PT**  | Profile Torque              | Drive 依 Profile 執行 Torque Control                 | ❌ 此 Sample 不支援 |

## 4. 馬達、Encoder 與 Servo Control

| 名詞                           | 全名                                 | 簡易解釋                                                                                                  |
| ---------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Servo Drive**              | Servo Drive                        | 接收 Position / Velocity 等 Command，透過閉迴路控制驅動 Motor 的控制器。                                                |
| **PMSM**                     | Permanent Magnet Synchronous Motor | 永久磁鐵同步馬達；此 Sample 的 Vector Control 主要控制對象。                                                            |
| **BLDC**                     | Brushless DC Motor                 | 無刷直流馬達；文件在 Kit / Inverter Board 圖中使用此名稱描述附屬 Motor。                                                    |
| **Inverter Board**           | Three-Phase Inverter Board         | 將 RZ/T2M 的 PWM Control Signal 轉成可驅動 Motor U / V / W 三相的功率輸出。                                          |
| **Serial Encoder**           | Serial Encoder                     | 以 Serial Protocol 回傳 Motor Position 的 Encoder；Motor Position / Electrical Angle Control 的重要 Feedback。 |
| **Vector Control**           | Vector Motor Control               | 將三相 Motor Current 轉換成容易獨立控制磁場 / Torque 的座標系進行控制。                                                      |
| **FOC**                      | Field-Oriented Control             | 常見的 Vector Control 方法；本專案名稱中的 `FOC` 即指此類控制架構。Startup Manual 文字主要使用 `Vector Control` 描述。               |
| **Position Control**         | Position Closed-loop Control       | 依 Target Position 與 Actual Position 誤差產生下一層 Velocity / Torque Command。                                |
| **Speed Control**            | Velocity Closed-loop Control       | 依 Target / Actual Speed 誤差產生 Torque / Current Command。                                                |
| **Current Control**          | Current Closed-loop Control        | 控制 Motor Phase / dq Current，是 Servo Control 最內層且最快的 Loop。                                             |
| **Trapezoidal Drive Motion** | Trapezoidal Motion Profile         | PP Mode 使用的加速 → 定速 → 減速 Profile。                                                                      |
| **Pole Pair**                | Motor Pole Pair                    | Motor 的磁極對數，會影響 Mechanical Angle 與 Electrical Angle 的換算。                                              |

## 5. Functional Safety / FSoE

| 名詞                     | 全名                                  | 簡易解釋                                                                           |
| ---------------------- | ----------------------------------- | ------------------------------------------------------------------------------ |
| **Functional Safety**  | Functional Safety                   | 系統即使發生 Fault，也要透過設計讓機器進入可接受的安全狀態。                                              |
| **FSoE**               | Fail Safe over EtherCAT             | 在 EtherCAT 上傳輸 Functional Safety Data 的 Safety Protocol。                       |
| **FSoE Master**        | Fail Safe over EtherCAT Master      | 發出 / 管理 FSoE Safety Communication 的 Master；Sample 使用 Beckhoff Safety System。   |
| **STO**                | Safe Torque Off                     | 禁止 Motor 產生驅動 Torque；不是主動煞車。                                                   |
| **SS1-t**              | Safe Stop 1 – Time Controlled       | 先依時間控制執行停止，再進入 Safe Torque Off。                                                |
| **HFT**                | Hardware Fault Tolerance            | Hardware Fault 容忍能力；此 Reference Software 以 **HFT = 1** 為目標。                    |
| **SafeData**           | Safety Data                         | Functional Safety Application 使用的安全資料內容。                                       |
| **Safety PDU**         | Safety Protocol Data Unit           | RZ/T2M 與 RZ/T2L / FSoE 之間交換的 Safety Protocol Packet。                           |
| **SafeInput**          | Safety Input                        | 送進 Safety System 的外部安全訊號，例如 Safety Switch 狀態。                                  |
| **SafeOutput**         | Safety Output                       | Safety System 輸出的安全控制 / 狀態訊號。                                                  |
| **ProcessData State**  | FSoE ProcessData State              | FSoE 正常交換有效 Safety Process Data 的狀態。                                           |
| **FailSafeData State** | FSoE FailSafeData State             | Safety Communication 未進入正常 ProcessData 時，使用安全預設資料的狀態。                          |
| **RZ/T2L-A**           | Functional Safety CPU Main          | 本 Kit 的 Main Safety Processor。                                                 |
| **RZ/T2L-B**           | Functional Safety CPU Sub           | 第二顆 Safety Processor，與 RZ/T2L-A 組成冗餘 Safety Architecture。                      |
| **PL-SW**              | Functional Safety Platform Software | RZ/T2L Safety Software Architecture 中使用的 Platform Software；負責 Safety 基礎處理、診斷等。 |
